=== Experiment 8: IPv4 / IPv6 & Address Mapping — Configuration ===

--- STATIC IP ASSIGNMENTS ---
Server:  IPv4 192.168.1.1 / 255.255.255.0  |  IPv6 2001:db8:1::1/64
PC0:     IPv4 192.168.1.2 / 255.255.255.0  |  IPv6 2001:db8:1::2/64  (or DHCP)
PC1:     IPv4 192.168.1.3 / 255.255.255.0  |  IPv6 2001:db8:1::3/64
PC2:     DHCP (auto-assigned)

--- DHCP SERVER SETTINGS (Server → Services → DHCP) ---
Pool Name:     LAN_POOL
Default GW:    192.168.1.1
DNS Server:    192.168.1.1
Start IP:      192.168.1.10
Subnet Mask:   255.255.255.0
Max Users:     50

--- ROUTER CONFIGURATION ---
interface Fa0/0
 ip address 192.168.1.1 255.255.255.0
 ipv6 address 2001:db8:1::1/64
 no shutdown
ipv6 unicast-routing

--- ARP TEST ---
PC0 Command Prompt:
  ping 192.168.1.3
  arp -a              (should show PC1's MAC)

--- DHCP TEST ---
PC2: Desktop → IP Config → DHCP → observe auto-assigned IP

--- IPv6 TEST ---
PC0 Command Prompt:
  ping 2001:db8:1::1
