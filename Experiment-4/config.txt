--- BLOCK CODING (PARITY) EXAMPLE ---
Data block:    1 0 1 1 0 0 1
Even parity:   1 (total 1s = 4, even → parity = 0)
Transmitted:   1 0 1 1 0 0 1 0

--- HAMMING CODE (7,4) EXAMPLE ---
Data bits: D3=1, D5=0, D6=1, D7=1
P1 (pos 1) = D3 XOR D5 XOR D7 = 1 XOR 0 XOR 1 = 0
P2 (pos 2) = D3 XOR D6 XOR D7 = 1 XOR 1 XOR 1 = 1
P4 (pos 4) = D5 XOR D6 XOR D7 = 0 XOR 1 XOR 1 = 0
Codeword: 0 1 1 0 0 1 1

--- CRC EXAMPLE ---
Data:      11010011101100
Generator: 1011 (degree 3)
Append 3 zeros: 11010011101100000
XOR divide by generator → Remainder = 100
Transmitted frame: 11010011101100 100
