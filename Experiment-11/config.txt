--- CONNECTIVITY TESTS ---

--- HTTP BROWSING ---
PC0 → Desktop → Web Browser → http://192.168.1.1
PC1 → Desktop → Web Browser → http://192.168.1.1

--- SIMULATION MODE SEQUENCE ---
Filter: TCP + HTTP
Step 1: ARP (PC0 resolves Server MAC)
Step 2: TCP SYN    — PC0:1025 → Server:80
Step 3: TCP SYN-ACK — Server:80 → PC0:1025
Step 4: TCP ACK    — PC0 confirms handshake
Step 5: HTTP GET   — "GET / HTTP/1.1"
Step 6: HTTP 200 OK — Server returns HTML
Step 7: TCP FIN/ACK — connection close

--- PORT NUMBERS ---
HTTP: Port 80 (Server listens)
HTTPS: Port 443 (Server listens)
Client (ephemeral): Port 1025+
